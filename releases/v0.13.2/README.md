# LocalWave v0.13.2

Real queue-order Shuffle.

Shuffle now physically reorders LocalWave's play queue and playback then follows that visible queue sequentially. The current song/history remain anchored when Shuffle is enabled mid-session, while new queues keep the selected song first and randomize the remaining tracks. Phone playback, Google Cast, and Samsung/DLNA/Whole House use the same queue ordering model.

Package: `app.localwave.player`  
versionCode: `36`
