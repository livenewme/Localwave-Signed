# LocalWave v0.11.0

Signed Android release, versionCode 30.

Adds Samsung/DLNA **Whole House** playback: select one, several, or all discovered TVs, pre-load the same local track/artwork, start the group against one monotonic deadline, and use manual/automatic drift correction while preserving the proven single-TV path.

Standard DLNA does not expose a shared hardware audio clock, so synchronization is intended for room-to-room listening rather than guaranteed sample-accurate phase alignment.
