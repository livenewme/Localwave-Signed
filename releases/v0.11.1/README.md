# LocalWave v0.11.1

Active Whole House synchronization repair after physical multi-room Samsung testing found several-second offsets in v0.11.0.

- Faster ~700 ms DLNA state/position polling while connected
- Automatic correction begins after ~1.2 seconds
- ~1.1 second drift threshold
- ~2.2 second correction cooldown
- Longer manual Resync pause/seek/start barrier
- Google Cast, single-TV DLNA, metadata/artwork, and startup isolation preserved
