# LocalWave v0.13.37 / code71

Adds LocalWave Backup & Restore plus explicitly-consented Data Consolidation for organizing visible music into a clean `Music/Artist/Album/NN - Title.ext` structure. Shadow Realm tracks are hard-excluded from consolidation at planning, write-batch, and per-file stages, including conservative MediaStore ID matching across legacy `external` and modern `external_primary` URI aliases.
